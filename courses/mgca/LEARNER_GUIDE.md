# MGCA GaussDB 认证课程 - 学习者指南

## 欢迎加入 MGCA GaussDB 认证课程

本指南旨在帮助您顺利完成 MGCA GaussDB 认证课程，掌握 GaussDB 的核心技能，为 MGCA Primary 认证和华为云 O&M 认证做好准备。

## 课程概述

### 课程目标

本课程将帮助您：
- 掌握 GaussDB 的核心架构和原理
- 熟练进行 GaussDB 的安装和配置
- 开发高效的 SQL 应用程序
- 掌握性能优化和故障诊断
- 实施完善的备份恢复策略
- 配置高可用架构确保业务连续性
- 实施数据库安全加固

### 适用人群

- 准备参加 MGCA Primary 认证的 DBA 候选人
- 准备参加华为云 O&M 认证的运维工程师
- 需要掌握 GaussDB 的开发人员和运维人员
- 企业内部负责数据库管理的工程师

### 前置要求

- 具备基本的数据库知识（了解表、索引、事务等概念）
- 熟悉 Linux 基本命令
- 了解 SQL 基础语法
- 具备基本的网络知识

## 学习路径

### 推荐学习顺序

1. **GaussDB 架构与原理** (建议 2 天)
   - 理解 GaussDB 架构
   - 掌握存储引擎和 WAL 机制
   - 了解查询处理流程

2. **安装与配置** (建议 2 天)
   - 学习安装流程
   - 掌握参数配置
   - 完成基础环境搭建

3. **SQL 开发基础** (建议 3 天)
   - 掌握 SQL 基础语法
   - 学习 DDL/DML 操作
   - 实践复杂查询

4. **性能优化** (建议 3 天)
   - 理解性能指标
   - 学习索引设计
   - 掌握查询优化

5. **备份与恢复** (建议 2 天)
   - 了解备份策略
   - 学习物理和逻辑备份
   - 掌握 PITR

6. **高可用架构** (建议 2 天)
   - 理解 HA 架构
   - 配置主备复制
   - 掌握故障切换

7. **安全与合规** (建议 2 天)
   - 学习安全原理
   - 配置访问控制
   - 实施审计和加密

**总建议学习时长：16 天（约 64 小时）**

## 学习环境准备

### 环境要求

- **操作系统**: Linux (Ubuntu 20.04+, CentOS 7+, macOS, Windows with WSL2)
- **Docker**: 20.10+ 和 Docker Compose 2.0+
- **内存**: 至少 8GB（推荐 16GB）
- **磁盘**: 至少 50GB 可用空间
- **网络**: 稳定的互联网连接

### 启动环境

```bash
# 1. 克隆课程仓库
git clone <repository_url>
cd <repository_path>/courses/mgca/environments/default

# 2. 启动环境
docker-compose up -d

# 3. 验证环境
docker-compose ps
```

### 连接数据库

```bash
# 连接主库
docker exec -it mgca-gaussdb-primary gsql -h localhost -U omm -d postgres

# 使用 gsql 命令
gsql -h localhost -p 5432 -U omm -d postgres
```

## 实验操作指南

### 实验环境使用

#### 实验难度分级

- **L1 (Entry)**: 基础操作，适合初学者

- **L3 (Advanced)**: 性能优化，需要深入理解

#### 实验步骤

   - 使用 `[[command]]{{RUN}}` 语法执行命令

   - 记录重要信息

3. **验证实验结果**
   - 使用验证查询检查结果

   - 保存实验脚本和结果
   - 按要求格式提交
   - 等待自动评分

#### 常用命令

```bash
# 查看容器状态
docker-compose ps

# 查看日志
docker-compose logs -f <service_name>

# 进入容器
docker exec -it <container_name> bash

# 连接数据库
gsql -h localhost -U omm -d postgres

# 执行 SQL 文件
gsql -h localhost -U omm -d postgres -f script.sql

# 导出数据
gs_dump -h localhost -U omm -d dbname -f backup.sql
```

### 快照和回滚


#### 恢复快照

```bash

```

### 故障排查

#### 常见问题

1. **容器启动失败**
   ```bash
   # 查看日志
   docker-compose logs <service_name>

   # 检查资源
   docker stats

   # 重启服务
   docker-compose restart <service_name>
   ```

2. **连接失败**
   ```bash
   # 检查端口
   netstat -tlnp | grep 5432

   # 测试连接
   gsql -h localhost -p 5432 -U omm -d postgres
   ```

3. **命令执行错误**
   ```bash
   # 检查语法
   gsql -h localhost -U omm -d postgres -c "<command>"

   # 查看错误信息
   docker-compose logs <service_name>
   ```

## 常见问题 (FAQ)

### Q1: 学习时间不够怎么办？

A1: 建议每天至少学习 2 小时，可以调整学习计划，将学习时间分散到周末。如果确实时间紧张，可以优先学习核心模块（架构、安装、SQL、性能）。

### Q2: 没有数据库基础可以学习吗？

A2: 可以，但建议先学习一些数据库基础概念。课程中有基础章节，可以边学边补。

### Q3: 实验失败多次怎么办？

A3: 不要气馁，先查看错误信息，参考故障排查指南。如果无法解决，在讨论区提问，提供详细错误信息。

### Q4: 如何判断自己是否准备好参加认证考试？

A4: 建议完成所有章节学习，通过模拟考试，对关键概念有深入理解，实验操作熟练。

### Q5: 认证考试难度如何？

A5: MGCA Primary 认证难度适中，需要扎实的理论基础和一定的实践经验。认真完成本课程学习后，通过率较高。
