## 学员管理

### 学员跟踪

#### 学习进度跟踪

```sql
-- 建议在数据库中建立学员进度表
CREATE TABLE learner_progress (
    learner_id VARCHAR(50),
    module_id VARCHAR(50),
    completed BOOLEAN,
    score INTEGER,
    completion_date TIMESTAMP,
    PRIMARY KEY (learner_id, module_id)
);

-- 查询未完成模块的学员
SELECT learner_id
FROM learner_progress
WHERE completed = FALSE
GROUP BY learner_id;
```

- 简化部分实验

**解决方案**:

- 分步骤详细讲解
