# MGCA GaussDB 认证课程

## 课程概述

本课程是为准备 MGCA Primary 认证和华为云 O&M 认证的学习者设计的完整 GaussDB 学习路径。课程采用四阶段企业培训模式，从理论基础到实战应用，全面覆盖 GaussDB 架构、安装配置、SQL 开发、性能优化、备份恢复、高可用和安全管理等核心主题。

## 课程模块

### 1. GaussDB 架构与原理 (60 min)
- GaussDB 核心架构和进程模型
- 存储引擎与 WAL 机制
- 查询处理与优化原理

### 2. 安装与配置 (90 min)
- 安装要求和准备工作
- 安装流程和配置
- 参数调优和性能配置

### 3. SQL 开发基础 (120 min)
- SQL 基础和数据类型
- DDL 操作（CREATE, ALTER, DROP）
- DML 操作（INSERT, UPDATE, DELETE）
- 查询和连接
- 高级 SQL 特性（CTEs, 窗口函数）

### 4. 性能优化 (90 min)
- 性能基础和指标
- 索引设计和优化
- 查询优化（EXPLAIN）
- 参数调优

### 5. 备份与恢复 (90 min)
- 备份概念和策略
- 物理备份（gs_basebackup）
- 逻辑备份（gs_dump/gs_restore）
- 时点恢复（PITR）
- 备份自动化和调度

### 6. 高可用架构 (120 min)
- HA 架构和概念
- 主备配置
- 故障切换和切换
- 多节点集群
- 跨区域容灾

### 7. 安全与合规 (90 min)
- 安全基础和威胁模型
- 用户管理和基于角色的访问控制
- 数据加密（静态和传输中）
- 审计和合规日志
- 行级安全和数据脱敏
- 安全加固最佳实践

## 交互式命令

课程使用自定义 Markdown 扩展语法实现交互式命令执行：

- `[[command]]{{RUN}}` - 执行命令
- `[[command]]{{PRINT}}` - 仅打印不执行

示例：
```markdown
登录数据库：
`[[gsql -d postgres -p 5432]]{{RUN}}`

查看表结构：
`[[\d table_name]]{{PRINT}}`
```
