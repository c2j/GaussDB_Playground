### 本章关键知识点

1. **性能基础和指标**
   - 响应时间、吞吐量、并发性
   - CPU、内存、I/O、网络利用率
   - 系统视图：pg_stat_database, pg_stat_user_tables, pg_stat_user_indexes
   - 慢查询监控：pg_stat_statements, 慢查询日志

2. **索引设计和优化**
   - 索引类型：B-tree, Hash, GiST, GIN, SP-GiST
   - 索引设计原则：选择性、复合索引顺序、覆盖索引
   - 部分索引、表达式索引、只索引
   - 索引维护：ANALYZE, REINDEX, 删除未使用索引

3. **查询优化（EXPLAIN）**
   - 执行计划分析：节点类型、成本、实际时间
   - 常见节点：Seq Scan, Index Scan, Nested Loop, Hash Join
   - 优化技巧：避免 SELECT *、使用索引列、避免 LIKE 前模糊
   - 并行查询优化：max_parallel_workers_per_gather

4. **参数调优**
   - 内存参数：shared_buffers, work_mem, effective_cache_size
   - I/O 参数：random_page_cost, effective_io_concurrency
   - WAL 参数：wal_buffers, checkpoint_timeout
   - 并行参数：max_parallel_workers
   - 连接参数：max_connections
   - 自动清理参数：autovacuum, autovacuum_max_workers

## 常见问题排查

### 查询慢
1. 使用 EXPLAIN ANALYZE 分析执行计划
2. 检查是否使用了索引
3. 查看是否有全表扫描
4. 检查连接方法是否合理
5. 考虑添加或优化索引

### 缓存命中率低
1. 增加 shared_buffers
2. 检查 work_mem 是否合理
3. 优化查询减少扫描数据量
4. 考虑使用覆盖索引

### CPU 使用率高
1. 检查是否有慢查询
2. 查看 work_mem 是否过大
3. 考虑降低并行度
4. 检查是否有死锁或锁等待

### I/O 瓶颈
1. 优化随机 I/O 成本
2. 增加 wal_buffers
3. 调整检查点参数
4. 考虑使用 SSD
