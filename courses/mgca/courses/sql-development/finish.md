### 本章关键知识点

1. **SQL 基础和数据类型**
   - 数据类型：数值、字符串、日期时间、布尔、二进制
   - 常量：字符串、数值、日期、NULL
   - 运算符：算术、比较、逻辑、字符串
   - 类型转换：隐式和显式转换

2. **DDL 操作**
   - CREATE TABLE：创建表和约束
   - ALTER TABLE：修改表结构
   - DROP TABLE：删除表
   - CREATE INDEX：创建索引
   - CREATE VIEW：创建视图
   - 约束：PRIMARY KEY, NOT NULL, UNIQUE, CHECK, DEFAULT, FOREIGN KEY

3. **DML 操作**
   - INSERT：插入数据
   - UPDATE：更新数据
   - DELETE：删除数据
   - TRUNCATE：快速清空表
   - UPSERT：INSERT ... ON CONFLICT
   - RETURNING：返回操作的数据

4. **查询和连接**
   - SELECT：基础查询
   - 聚合函数：COUNT, SUM, AVG, MAX, MIN
   - GROUP BY：分组
   - HAVING：过滤分组
   - JOIN：INNER, LEFT, RIGHT, FULL
   - 子查询：WHERE, FROM, EXISTS, IN
   - UNION：合并结果集
   - CASE：条件表达式

5. **高级 SQL 特性**
   - CTE：公共表表达式
   - 窗口函数：ROW_NUMBER, RANK, LAG, LEAD, SUM OVER
   - 递归查询：处理层次数据
   - 分析函数：PERCENT_RANK, NTILE
   - 数组函数：ARRAY_AGG, UNNEST
   - JSON 函数：JSON 操作

## 常见问题排查

### 查询慢
1. 使用 EXPLAIN ANALYZE 分析执行计划
2. 检查是否使用了索引
3. 查看是否有全表扫描
4. 检查连接方法是否合理

### 类型错误
1. 检查数据类型是否匹配
2. 使用显式类型转换
3. 检查 NULL 值的处理

### 连接问题
1. 检查连接条件是否正确
2. 确认外键关系
3. 考虑使用合适的 JOIN 类型
4. 检查是否有笛卡尔积
