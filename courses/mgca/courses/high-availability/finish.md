## 常见问题排查

### 切换失败
1. 检查备节点状态
2. 验证数据同步完成
3. 检查网络连接
4. 查看错误日志

### 复制延迟
1. 检查网络带宽
2. 查看备节点负载
3. 检查 WAL 日志量
4. 优化网络配置

### 集群节点故障
1. 使用 CM 查看节点状态
2. 检查节点日志
3. 尝试重启节点
4. 必要时从集群移除

### 数据不一致
1. 验证复制模式
2. 检查复制状态
3. 使用同步复制
4. 定期验证数据一致性
