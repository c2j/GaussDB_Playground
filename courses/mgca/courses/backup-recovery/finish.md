## 常见问题排查

### 备份失败
1. 检查磁盘空间是否足够
2. 验证用户权限
3. 查看备份日志获取错误信息
4. 检查数据库状态

### 恢复失败
1. 检查备份文件完整性
2. 验证 WAL 归档文件是否完整
3. 查看恢复日志
4. 检查配置文件是否正确

### PITR 问题
1. 确认 WAL 归档已启用
2. 验证恢复目标时间在备份之后
3. 检查 WAL 归档文件是否连续
4. 监控恢复进度
